# Porometry Analyzer - notes for Claude

PyQt6 desktop app that replaces PMI's CapRep for capillary flow porometry data from the lab's
**PMI CFP-1500AEX** (CapWin `.CFT` files). Part of Brandon's UAkron lab workspace (shared conventions in
`../CLAUDE.md` when the repos are cloned side by side in `GitHub Projects/UAkron/`). GitHub:
`brandonbtm29/Porometry-Analyzer` (public, MIT).

## Run / test

```powershell
.venv\Scripts\Activate.ps1          # Windows (Python 3.12); macOS uses ~/.venvs/porometry-analyzer
pytest                               # synthetic tests always run; lab-data tests skip without SyncThing
porometry                            # GUI (or Porometry Analyzer.bat / .command)
porometry-cli <folder> --excel out.xlsx --figures figs
python tools/caprep_check.py         # re-check against CapRep's own reports (needs pip install -e ".[validate]")
```

- If `.venv` is missing: `py -3.12 -m venv .venv; .venv\Scripts\python -m pip install -e ".[dev]"`.
- GUI tests run headless with `QT_QPA_PLATFORM=offscreen`. The fixture clears the app's QSettings afterwards.
- `examples/compare_conditions.ipynb` is a template generated by `examples/build_notebook.py`; edit the builder and rerun it. It must stay output-free (`test_template_notebook_has_no_outputs`). Brandon's working copy with results is `Capillary Flow Porometer/Notebooks/compare_conditions.ipynb` in SyncThing; the `Open Notebook` launchers create and open it.

## Layout

| Module | Role |
|---|---|
| `cft.py` | `.CFT` parser -> `Run` (header, wet/dry `Curve`s sorted by pressure) |
| `analysis.py` | CapRep math -> `Analysis` (BP, MFP, smallest pore, CFF, PSD point-by-point / binned) |
| `qc.py` | data-quality checks -> `QCReport` (pass/info/warn/fail); uses the raw CFF (`Analysis.cff_raw`) |
| `workspace.py` | loaded runs, stable colours, duplicate grouping (auto + manual overrides), summary/group tables |
| `export.py` | Excel (Summary, Groups, QC, one sheet per run) / CSV, figures |
| `figures.py` | matplotlib drawing shared by GUI and export; colour-blind-checked palette, never cycled past 8 |
| `gui/` | `main_window.py` (tree of runs, 3 plot tabs, run + group tables, settings dialog) |
| `tools/caprep_check.py` | compares `analyze()` with every CapRep `.xls` report found next to its `.CFT` |

## Verified against CapRep (do not "fix" these without new evidence)

Checked on 12 Oct 2026 against 311 CapRep reports in `C:\CFP-1500AEX\StudentData` (2015-2026). Run
`tools/caprep_check.py` after any change to `cft.py` or `analysis.py`.

- **CFT format:** header `key=value` lines, date, 2 blanks, then fluid, surface tension (stored negative, use abs), diameter cm, thickness cm, a flag. Then curve rows `flow (cc/min), pressure (psia)`; each curve ends with `0,0`; then parameter lines `B,...`/`W,...`/`D,...`. **The first curve is always the wet curve**, also for "Dry Up/Wet Up" runs (all 14 such reports).
- **dP = P - first wet point pressure** (ambient, about 14.7 psia). **D (um) = 0.415 x gamma / dP(psi)**; 0.415 = 4 x 0.715 / 6.894757, 0.715 = CapWin's "Tortuosity Factor".
- **Dry flow at wet pressures:** linear interpolation; past the last dry point, the least-squares line through the last 3 dry points (median error 0.003 % on 125 reports).
- **CFF as CapRep reports it:** wet/dry x 100, running maximum, capped at 100 %. `Analysis.cff` is this; `Analysis.cff_raw` is the plain ratio.
- **Bubble point = first wet point with flow > 0** (309/311; also matches CapWin `log.txt` exactly for the test runs). A 1 cc/min threshold does NOT match. Deliberate difference: a point below 0.5 kPa whose wet flow exceeds the dry flow is a start-up blip and is skipped (CapRep is fooled by these in 2 reports).
- **Mean flow pore** = where the wet curve crosses half the dry curve, both piecewise linear on their own points (99 % within 0.1 %). Not the 50 % crossing of interpolated CFF. When wet > half dry already at the first point, CapRep still prints a number (13 reports, rule unknown); we report none.
- **Smallest detected pore** = first measured point with (CapRep) CFF >= 98 %, no interpolation; the CFF peak if never reached (98 % within 0.1 %).
- **PSD** = dCFF / dD at the average D (manual 5.1 and the lab's current CapRep). Some older exports use dCFF / dD^2 (weighting `"dD2"`). The help file's "FFP = CFF - Last FFP" is a typo.
- CapRep's "X % Cumulative Filter Flow occurs at" lines are often out of order; don't use them as a reference.
- CapRep's "The data file cannot be processed" = a dry curve with too few points.

## Decisions made with Brandon

- PyQt6 desktop app (not Streamlit). Pressure in **kPa by default**, psi toggle. Diameters in um.
- Duplicates: automatic grouping by file name (strip `_TEST#`, then `_S#`), plus manual "Mark as duplicates", "Not duplicates" and "Reset" (stored in QSettings `group_overrides`). Group stats = mean +- SD. QC fails are never averaged; warns are, unless turned off in Settings.
- Runs that fail QC still plot, dashed and labelled `[QC fail]`.
- Analysis settings are stored in QSettings key `analysis_v2` (the old `analysis` key held the pre-check smallest-pore level and is ignored).
- Public repo, MIT license; data in SyncThing (12 Oct 2026).
